# 文献速读卡字段规范

## 速读卡最小结构

```text
题名 / 作者 / 年份 / 来源 / DOI
一句话判断
关键数据：样本量、效应量、比例、时间点或研究数量

01 核心结论
- 结论 1：变量关系 + 关键数据
- 结论 2：变量关系 + 关键数据
- 结论 3：仅在确有第三条时填写

02 研究方法
样本/数据 + 工具/变量 + 设计 + 分析方法（一句话）

03 可引用点
- 可引用结论；出处：摘要/结果/表或图/讨论/页码
- 可引用结论；出处：...

04 局限与注意
- 因果：能否推断因果，以及原因
- 样本/外推：谁被纳入、谁没有被纳入
- 测量/设计：自陈、横断面、共同方法偏差等
- 情境：特殊时期、单一地区或特殊群体
术语注释：专业术语 + 简短中文解释
```

## 结论写法

- 先写方向，再写数字：例如“社会联结缓冲压力对心理健康的不利影响；纵向数据中……”。
- 只写来源明确给出的数字。没有效应量时，不要自行估算；可以写“研究报告为显著/不显著”，但要注明来源位置。
- 元分析写总体效应、研究数、样本数和异质性/偏倚；随机对照写组别、样本量和主要结局；纵向研究写时间点和预测关系。
- 横断面相关研究只能写“相关”“关联”“与……同时出现”，不能写“导致”“提升了”“产生了影响”。

## 可引用点写法

使用“结论 + 使用场景 + 出处位置”的格式：

```text
可用于论证大学生社会联结与心理健康有关；出处：结果部分，相关/回归分析表。
```

如果只能看到摘要，写“出处：摘要”，不要伪造正文页码。将作者自己的解释与数据结果分开：结果可以直接转述，机制解释通常需要加“研究者认为”或“提示”。

## 术语注释示例

- 横断面设计：同一时间点收集数据，适合描述关联，不支持时间先后判断。
- 纵向设计：对同一批对象进行多次测量，能更好观察变化和时间顺序，但仍不自动等于因果。
- 中介效应：检验一个变量是否解释另两个变量之间的作用路径。
- 调节效应：检验某变量是否改变另一关系的方向或强弱。
- 元分析：用统计方法合并多项研究的效应结果。
- 随机对照试验：通过随机分组比较干预组与对照组，是检验干预因果效果的较强设计。
